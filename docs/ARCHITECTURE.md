# 实现与边界

## 配置修改

电脑端复用固定 revision 的 zte-config-utility 进行编码与 AES 解码。额外检查外层 60 字节 Type 4 头、单个 AES 块的长度、内层压缩头与块偏移、两类 CRC、解压大小上限和 XML 结构。

脚本先要求原始文件编码往返逐字节一致，再进行局部字节替换，不使用 XML 序列化器重写整份配置。因此除 TelnetCfg / Row 0 的 TS_Enable、Lan_Enable 值外，配置字节保持原样；账号、密码、Wi-Fi 与其他数据库内容全部沿用用户自己的值。

所有内容检查在创建输出目录前完成。输出目录必须不存在，输出文件以排他创建方式写入，Unix 权限为目录 0700、文件 0600。Windows 文件权限还应由操作系统 ACL 保护。

## 独立 SSH 运行库

原厂用户空间不能直接运行所选 Entware Dropbear，且根文件系统只读。本项目仅对下载并验证的 SSH 专用二进制做等长替换：

| 原路径 | 新路径 | 作用 |
| --- | --- | --- |
| /opt/lib | /var/zsl | 指向 /Plugin/sr7410-ssh/lib |
| /opt/etc | /var/zse | 指向系统 /etc，只读取账户等配置 |
| /dev/ptmx | /var/ptmx | SSH 专用 libc 的 PTMX 路径 |
| /dev/pts | /var/pts | SSH 专用 libc 的终端路径 |

每个文件先核对已验证的上游二进制 SHA256，再核对替换次数，最后要求文件长度不变。它不是通用 ELF 修改器，只接受锁定版本。

启动脚本使用 newinstance 挂载独立 devpts。系统 /dev、系统运行库与原厂账户文件均不修改。已存在但指向其他运行环境的短路径会导致停止安装，避免接管其他软件。

## 安装与认证

安装包通过电脑 LAN 地址临时提供，端点使用随机路径，并限制连接源为指定路由器。HTTP 服务不共享目录或其他文件，传输完成即关闭。Telnet 本身没有加密，初次认证与主机公钥固定依赖当前可信 LAN 会话。

原厂没有 sha256sum 或 base64，因此通过 hexdump 回读下载文件，电脑比较完整字节。只在一致后解包执行。公网 Entware 包另与仓库锁定的 SHA256 比较。

只传输用户自己的 Ed25519 公钥，移除其注释；私钥不读取上传、不放入安装包。SSH 主机私钥在设备上生成并持久保存。设备主机公钥通过 Telnet 获取到本地 known_hosts，而非跳过主机身份检查。

SSH 使用系统原生 UID 0 账号，关闭密码认证，监听 LAN IPv4 与回环地址，不添加 WAN 监听或防火墙规则。本地客户端配置写入 Git 忽略的 private 目录。

## 自启与回退

原厂 /etc/init.norm 优先从 /apps/apps/dlspeed_rt.tar.gz 解压组件，其中 /apps 指向 /Plugin；否则使用 /etc/dlspeed_rt.tar.gz。

电脑首先确认原厂组件 SHA256 与实测版本相同，保留归档全部成员，只修改 dlspeed_rt/dlspeed_monitor.sh，添加受 autostart.enabled 标记控制的后台启动语句。SSH 初装通过 Telnet 完整回读核对，后续 Larktun 通过严格主机校验的 SSH 更新共享入口。原厂只读组件始终保留。

启用时拒绝其他软件已经存在的覆盖包。保存本工具创建包的完整副本，禁用时使用 cmp 逐字节核对归属，避免删除后来被其他软件改动的包。禁用标记后，即使之前解压出的 monitor 仍存在，也不会再次触发 SSH 自启。

卸载只停止 PID 文件对应且命令行属于本工具的进程，不使用 killall dropbear。RAM 中可能被其他进程使用的 PTY 挂载不强制卸载，下一次重启自然释放。

## Larktun

Larktun 安装器依赖已经配置的 SSH。构建器从官方 HTTPS 下载锁定的静态 ARM64 二进制，检查大小、SHA256、架构及不存在动态 ELF 解释器；压缩副本与独立 CA 证书写入可写闪存，运行程序在 RAM 中解压。每台设备自行生成状态，构建包不含身份材料。

安装包和 Auth Key 都通过已有严格主机校验的 SSH 通道发送，不重新开启文件共享或关闭 SSH 主机校验。Key 从隐藏终端输入直接进入 SSH stdin，仅在路由器 RAM 文件中短暂存在，以 file: 参数读取；正常退出和常见中断信号会清理文件。授权结果的原始错误输出不直接回显，避免泄漏 Key 或登录链接。

用户态模式不依赖原厂 TUN，也不会自动接管家庭 LAN。显式 TCP Serve 将私网端口转给回环地址的原厂 HTTP / Dropbear，保留原认证方式。独立私网 SSH 配置从已固定的 LAN 主机公钥派生，新增文件保持私有，不改变 LAN 连接配置。

共享启动钩子在 SSH 自启标记存在时启动 SSH，并在 Larktun 标记也存在时后台启动 Larktun。刷新入口前后均检查包归属与组件内容，只更新本仓库持有的快照与覆盖包，避免与原有 SSH 回退逻辑冲突。单独禁用 Larktun只移除自己的标记；禁用 SSH 自启会禁用整个共享入口。

Larktun 卸载删除自己的程序、RAM 文件及节点状态，保留 SSH，控制台节点由用户另行清理。完整卸载应先处理 Larktun，再处理共享入口的 SSH。
