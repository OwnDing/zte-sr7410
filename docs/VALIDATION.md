## 尚需在每台目标设备上完成

**整理后的通用 install-ssh / enable-autostart / uninstall-ssh 没有在已配置设备上进行破坏性重装或完整卸载回归。** 这里区分已经成功的设备原理流程、整理版组件验证，以及一台全新设备的完整安装验收。

新用户请按 README 顺序完成：

1. 核对完整型号与固件，保留自己的原始配置。
2. 导入脚本生成的配置，确认重启后 Telnet 可登录 UID 0 Shell。
3. 安装 SSH，运行 verify-ssh，确认命令执行与交互 PTY 均通过。
4. 如需自启，启用后自行重启，再运行 verify-ssh。
5. 需要回退时，先卸载本工具 SSH，再恢复自己的原始配置。

其他型号、固件、原厂组件版本和已存在第三方覆盖包的环境，不在当前设备验收范围内。脚本保守拒绝已知不匹配情况；请勿取消校验以绕过错误。
